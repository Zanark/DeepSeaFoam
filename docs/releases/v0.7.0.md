# DeepSeaFoam 0.7.0

Eight added destinations bring the collection to **21 targets**. The requested
BetterDiscord support reuses the existing Discord CSS rather than duplicating
the palette or counting one integration twice.

| Addition | Delivered format |
| --- | --- |
| Notepad++ | Native XML: 22 language lexers plus search results and 53 global styles |
| Zsh | Dependency-free `.zsh-theme` prompt; optional existing Oh My Zsh integration |
| rofi | Native `.rasi`, explicitly based on the default layout |
| Xfce4 Terminal | Native `[Scheme]` color preset |
| Termux | `colors.properties`, recognized foreground/background/cursor and ANSI slots |
| GitHub Pages | Static HTML/CSS starter plus optional Jekyll layout/configuration example |
| Godot Engine | Native `.tet` script-editor theme, 49 recognized color keys |
| Nova Launcher | **Manual color reference and setup guide**, not a native importer |
| BetterDiscord | Named `.theme.css` release alias, byte-identical to the Discord asset |

Every new target includes installation, restore instructions, format references
and explicit limits. Native exports do not replace entire application settings.
Godot chrome and Notepad++ Dark Mode chrome are separate manual options.
Zsh changes the prompt, not the terminal emulator. Termux has no selection-color
property. Nova's current documented text controls are separated from historical
background/accent paths; its picker grammar and current native runtime are not
represented as verified.

## Consistency

All **27 core values, four syntax heritage values and 19 terminal colors are
unchanged**. New terminal ports use the existing higher-contrast group where the
host exposes it. Editor/web syntax keeps seafoam strings, green keywords, yellow
numbers, warm functions and blue types. Selection uses the shared native-alpha
or opaque-composite mapping appropriate to the host.

## Showcase and packaging

The gallery adds eight cards and makes BetterDiscord visible on the existing
Discord card. Five new product marks have pinned sources, unchanged geometry
and disclosed brand-color fills. Godot's CC BY 4.0 credit remains distinct from
CC0. Termux uses its unmodified geometric mark with Commons PD-shape provenance.
rofi and Nova use original text identifiers, not fabricated official logos.
Three larger new marks are served as lossless 144px WebP; their exact SVG render
sources remain in the repository, outside the deployed site.

The eight-card expansion receives an explicit **16 KiB allowance**: non-photo,
non-audio assets rise from 256 to **272 KiB**; the photo remains capped at 48 KiB,
non-audio assets at **320 KiB**, and **all deployed files at 3 MiB**. Every notice
and license still counts. Existing music and photograph assets remain unchanged.
Music now also attempts startup on the first wheel/trackpad or single-finger
scroll gesture, alongside tap/click/key recovery. Browser autoplay policy may
still require a tap or click; explicit Cancel/Pause remains authoritative.

Packaging stays within `dist\releases\<version>`. Earlier releases, the six-post
Instagram kit and installed application settings are not modified. The Pages
archive preserves `.nojekyll` and nested assets. Nova's ZIP contains a manual
reference, not a restore payload.

## Publication and validation boundaries

Source/schema checks are not installed-client visual coverage. The static
Pages example is browser-runnable; optional Liquid needs a real Jekyll build.
No new marketplace application, directory PR, account, signing, agreement or
owner declaration is implied by this release. VS Code's existing public listing
and the Sublime distribution remain separate published versions.
