# DeepSeaFoam 0.6.0

**Adds Monkeytype native sharing. [Built-in preset PR #8421](https://github.com/monkeytypegame/monkeytype/pull/8421) is submitted and awaiting review, not merged or deployed.**

## Thirteen targets, unchanged palette

- Adds [Monkeytype](../../targets/monkeytype/README.md) as the thirteenth
  application target. All original palette, syntax-heritage and terminal colors
  remain unchanged.
- Uses the native ten-slot custom-theme share object, `{c: [...]}`, encoded as
  ordinary Base64 in a `https://monkeytype.com?customTheme=...` URL.
  No extension, injected CSS, wallpaper or full-settings import is required.
- Maps base/panel to `#000F13` / `#001E26`, main/caret to `#00A591`,
  secondary/untyped text to `#839496`, normal typed text to near-white
  `#EEE8D5`, and all four error roles to `#E84A5F`. Flip and colorful modes
  retain their native behavior.
- The share link preserves unrelated settings and separate backgrounds/custom
  CSS. The guide explains backing up existing custom colors, applying without
  account login and restoring the former preset/custom colors.

## Release packaging

- Adds `DeepSeaFoam-Monkeytype-0.6.0.zip`, containing `DeepSeaFoam.json`,
  `DeepSeaFoam.txt`, `README.md` and `LICENSE` at its root.
- `npm run package:release` now recreates only `dist\releases\0.6.0\`, not all
  of `dist`. Other release versions, the historical manual-upload kit and
  `dist\instagram\` remain untouched. Re-running it replaces only the selected
  local version directory; published assets are never replaced by this command.
- Expected release inventory: thirteen target artifacts, the complete source
  bundle, the theme-license companion and `SHA256SUMS.txt` — sixteen files,
  with fifteen payload digests. The new manual VS Code kit lives under
  `dist\releases\0.6.0\marketplace\vscode\`.

## Showcase and verification boundaries

The gallery now has thirteen cards. Product artwork retains its source/license
provenance and does not imply endorsement. Both the 3 MiB all-file cap and
256 KiB non-audio cap remain unchanged; shipped licenses count toward them.
See [application artwork provenance](../application-icons.json).

The source bundle includes the current underwater showcase: eligible
fresh visible loads preload music during the intro and attempt playback only
after dive completion. Skipped/reduced-motion intros can complete immediately.
Blocked autoplay keeps a request ready for a genuine tap or key without requiring
the Play button; browser policy still controls whether audible playback is allowed.
Explicit Cancel/Pause, real failures, hidden/pagehide and history restoration
suppress further automatic retries. Music and motion buttons gain a subtle static
seafoam border/halo, independent of motion. This is not a claim of zero-interaction
playback in every browser.
Theme/code MIT licensing still excludes separately documented third-party artwork
and the supplied music.

Repository checks cover deterministic/nonmutating generation, palette
propagation, native slot order, share-URL round-trip, license copies, packaging
boundaries and the gallery contract. The actual Monkeytype share link was also
exercised in disposable Edge across all four flip/colorful modes, including
typed/untyped/error/extra/caret colors, preservation of unrelated preferences
and native preset restoration. This does not establish every-browser support,
marketplace updates or upstream inclusion. Track actual submission and review
receipts in [publication status](../PUBLISHING.md).
