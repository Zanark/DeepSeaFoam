# DeepSeaFoam 0.5.0

Seven additional application targets, a freely roaming foreground nautilus, and a credited photographic reference. **The palette colors are unchanged.**

## Twelve app-specific targets

The original VS Code, Visual Studio, Obsidian, Windows Terminal and Firefox exports are joined by:

| Addition | Release artifact and scope |
| --- | --- |
| Discord | Optional `.theme.css` for already-modified clients; unofficial and potentially contrary to Discord's terms. Native Nitro controls are documented as a manual approximation. |
| Telegram Desktop | Native plain-text `.tdesktop-theme`, with dark core surfaces, chat bubbles, controls and readable metadata; no bundled wallpaper. |
| Slack | Four-color CSV preset for native custom-theme controls, not a full-client recolor. |
| Chrome / Edge | Color-only MV3 Chromium theme ZIP; extract before using Load unpacked. Edge-only surfaces are not guaranteed. |
| JetBrains IDEs | Resource-only JAR with Islands Dark inheritance and an editor scheme; requires 2025.3+. |
| Sublime Text | Native editor/syntax color scheme, paired with the built-in Adaptive UI rather than claiming a complete UI replacement. |
| Alacritty | Colors-only TOML fragment using the unchanged 19-color terminal extension. |

Each target includes install, restoration, limitation and source-reference documentation. Nothing installs automatically or modifies existing application settings. The generator now emits 64 files; release packaging supplies twelve target artifacts, the complete bundle, and `SHA256SUMS.txt`. Earlier release assets remain immutable.

See [application mappings](../MAPPINGS.md) and the [target directory](../../targets).

## Showcase updates

The nautilus now moves left/right/up/down/diagonally across a fixed foreground layer, independent of page scrolling. Nominal targets are **30-84 CSS pixels per second, 3x the previous targets**, with smooth turns and soft edge slowing. Bubbles paint above it; clicks and touches pass through. Phone zoom follows the visible viewport, and pause, reduced-motion and no-JavaScript fallbacks remain available.

The gallery now presents twelve targets with original-color SVG product marks and accompanying notices. Its complete asset allowance is 256 KiB, including all artwork, scripts and license files; no large photograph is loaded automatically.

The visual inspiration is [Bay with Orange Seashore Under White and Gray Clouds](https://www.pexels.com/photo/bay-with-orange-seashore-under-white-and-gray-clouds-8567869/) by [JJ Perks](https://www.pexels.com/@jj-perks-868548/). The website and README link to the **[7952 x 5304 original](https://images.pexels.com/photos/8567869/pexels-photo-8567869.jpeg)** rather than bundle it. The source metadata is recorded in [showcase-artwork.json](../showcase-artwork.json); no pixel-sampling or universal eye-comfort claim is made.

This source bundle also includes the phone tap/swipe water and immediate touch-bubble improvements previously delivered on `main`. See [SHOWCASE.md](../SHOWCASE.md) for architecture and evidence limits.

## Compatibility and verification boundary

Exports and packages can be structurally checked without installing them in every application. No universal native-app visual compatibility or physical-phone/Safari audit is claimed. Discord variables are internal, Slack derives colors, Telegram wallpaper remains separate, and Firefox/Visual Studio retain their previously documented signing or host-specific packaging requirements.
