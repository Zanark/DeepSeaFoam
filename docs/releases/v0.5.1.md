# DeepSeaFoam 0.5.1

## Original theme/code licensing

The original application theme files and generator/supporting code are now
MIT-licensed with the owner's approval. Every target directory carries the
license; native archive packages include it, including the JetBrains JAR.
A separate `DeepSeaFoam-Themes-LICENSE.txt` accompanies single-file downloads.

This is not a blanket license for the showcase. Third-party product marks,
photographs and supplied artwork retain their existing rights and notices.
The blobfish illustration still has no established redistribution license.

## Publication preparation

The VS Code extension now declares MIT instead of UNLICENSED. Marketplace
registration, authenticated submission, review and public approval remain
separate steps; see [publication status](../PUBLISHING.md).

Theme colors, terminal values and application mappings are unchanged.
The source bundle includes the newer background-nautilus website correction.
Earlier versioned release assets remain untouched.
