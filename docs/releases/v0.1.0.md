# DeepSeaFoam 0.1.0

First cross-application release of DeepSeaFoam.

## Included

- Canonical machine-readable palette with 11 interface solids, 8 transparent overlays, and 8 preview neutrals.
- Visible local swatches and documented application mappings.
- Visual Studio Code color-theme extension.
- Visual Studio `.vstheme` source with Visual Studio 2022 editor categories and Visual Studio 2026 semantic shell tokens.
- Obsidian app theme.
- Windows Terminal color scheme.
- Firefox static WebExtension theme.
- Complete source bundle and SHA-256 checksums.

## Installation boundaries

- The VS Code VSIX can be installed directly.
- The Obsidian ZIP contains a ready-to-copy `DeepSeaFoam` theme folder.
- The Windows Terminal JSON is one scheme object, not a complete `settings.json`.
- The Visual Studio file is portable theme source and must be packaged with Color Theme Designer for the target Visual Studio version.
- The Firefox ZIP can be loaded temporarily from `about:debugging`; permanent distribution requires Mozilla signing.

No package changes live application settings automatically.
